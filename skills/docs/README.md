# Docs Skills

Document generation — presentations, SOPs, invoices, statements, and reports.

## Skills

| Skill | Command | Description |
|-------|---------|-------------|
| [generate-ppt/](generate-ppt/) | `/generate-ppt` | HTML presentations with Potential Inc branding |
| [generate-sop/](generate-sop/) | `/generate-sop` | SOP creation + Notion integration |
| [generate-invoice/](generate-invoice/) | `/generate-invoice` | Invoice (견적서) HTML/PDF |
| [generate-statement/](generate-statement/) | `/generate-statement` | Transaction statement (거래명세서) HTML/PDF |
| [generate-project-report/](generate-project-report/) | `/generate-project-report` | Government project result report |
| [generate-random-project/](generate-random-project/) | `/generate-random-project` | Random project specs for team training |
| [review-command/](review-command/) | `/review-command` | Skill file validation and compatibility check |

## Naming Convention

- **Operations repo**: `skills/docs/{skill-name}/`
- **Global skills** (`~/.claude/skills/`): `{skill-name}/` (e.g., `generate-ppt/`)
- **Slash commands**: `/generate-ppt`, `/generate-sop`, etc.
